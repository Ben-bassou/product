# 🛒 Boutique E-Commerce (Style SaharaLuxury)

Projet de site web e-commerce complet prêt à être hébergé gratuitement sur **GitHub Pages**.

---

## 🚀 Mise en Ligne sur GitHub Pages

1. Créez un nouveau dépôt public sur GitHub.
2. Téléversez les fichiers du dossier (`index.html`, `style.css`, `script.js`, `README.md`).
3. Allez dans **Settings** > **Pages**.
4. Sous **Branch**, choisissez `main` puis cliquez sur **Save**.
5. Votre site sera disponible en quelques instants !

---

## 💻 Structure des Fichiers

- `index.html` : Structure et catalogue des produits.
- `style.css` : Design responsive et moderne.
- `script.js` : Gestion dynamique du panier.
- `README.md` : Instructions du dépôt.
